How To Run

  1. Create a .config using the template. Set input_csv, output_dir, and decoy_database. Match decoy_string to the target-decoy FASTA and review the indexing, Percolator, filtering, and consensus settings.

  2. Create an input CSV using the template. List the sample or plex name and idXML result for each search engine. Use absolute idXML paths. For MSBooster, also create an mzML CSV with one row per fraction and set input_mzml_csv.

  3. Initialize the Git submodules and run the pipeline with Nextflow, for example:

bash export NXF_VER=24.10.6 export NXF_SYNTAX_PARSER=v1 nextflow run TheBoutrosLab/pipeline-validate-ProteomicPSM -r <version> -c config/my-run.config

The supplied configuration template defaults to Docker. Use -profile apptainer or -profile singularity when appropriate for the execution environment. The local profile uses installed executables for development. The .env-template records the Nextflow version used by the shared SBP configuration modules.
